## Brief
Implement the 기록 (history) tab — MVP-SPEC.md §5 F8 (기록 content) + F9 (edit/delete) + §6 S3 (기록
screen) + S5 (detail sheet). This is the ledger-utility half of the app ("is my money OK?") — the
town/village visuals (S2) are all done; this task is the second tab, reachable from the bottom tab
bar mentioned throughout the spec but not yet built (check `App.tsx`/routing — if there's no tab bar
yet, add the minimal one this needs, don't over-build navigation beyond S2/S3).

**F8 · 기록 (history + stats)**: month header with ‹ › navigation. Totals 지출/수입/저축/순액;
budget-pace bar; expense category donut (descending, legend with amount and %); reverse-chronological
entry list grouped by day with day subtotals. No-spend days appear in the list as a distinct
zero-amount row. Tapping a row opens F9/S5.
AC: donut percentages sum to 100 within rounding; empty month → empty state, not a broken chart.

**F9 · Edit / delete an entry** (S5, sheet over S3): list row → detail sheet with the entry sheet's
fields (type/amount/category/date/memo) plus 삭제. Delete removes the entry **and its building**; the
consumed slot is **not refunded**. Editing amount/memo/date does not move the building; editing
**category** re-skins it to the new family, keeping the same plot. Editing the date across a month
boundary moves the entry between month chunks; the building stays in its `builtOn` chunk.
AC: delete → building count −1, the plot becomes an empty lot (remaining buildings do not shift —
this still holds under ADDENDUM-02's random/movable placement, since delete just frees a lot, it
doesn't reassign anyone else's). Slot counter unchanged. Destructive action confirms. Re-dating an
entry across months updates both months' totals and both chunks; a reload confirms it.

**Read the existing storage/selectors code before writing new code** — month-chunked storage
(`storage.ts`), `selectors.ts`'s existing month/donut/pace helpers if any already exist, and
`ladderFor`/`placement.ts` for how buildings are already keyed so delete/edit don't reinvent building
lookup.
