## Brief
Director feedback via Discord (2026-08-04): "건물 모양이 단순 네모야. 카드 안에 집모양 이미지를 추가해줘"
(the building shape is a plain square/rectangle — add a house-shaped image inside the card). This
matches T006's own QA finding, honestly reported at the time: "the buildings themselves are flat
colored rounded-rect chips with a single centered icon (no roof/window/door illustration) — closer
to a stylized icon-map than literal building art."

No real art order has been placed yet (D-12 in the MVP spec is still open — art-style closeness to
Fortune City needs the director's sign-off first). This task is about the PLACEHOLDER improving to
actually read as "a building" — not commissioning real art.

Current component: `app_in_toss/src/components/PlaceholderBuilding.tsx` (category colour + icon +
"a variant-driven roof shape" per the original MVP spec §6.1, but visually this isn't reading —
confirm what's actually there today before changing it).

**What to do**: add a clear house/building silhouette to the card — a simple gable or triangular roof
shape sitting on top of a body, rendered in CSS/SVG (no image assets — none exist yet), so each tile
unmistakably reads as a small house/building rather than a plain rounded-rectangle icon chip. Keep
the category colour and icon (they're doing real work — colour reads as category, icon reads as
specific type). The roof/house silhouette is additive, layered with them, not a replacement.

Keep it simple and CSS-only (no new dependencies, no new asset files) — this is still a placeholder,
just a better one. Verify visually in a browser, not just by reading the code; a "roof shape" that
doesn't actually read as a roof at real tile size (see T006's screenshots — tiles are small, ~50px
wide) is not done.
