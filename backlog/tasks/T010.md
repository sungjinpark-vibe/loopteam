## Brief
Turn the static village v2 into the first playable slice of Life Town's core loop: tap a building →
run a (focus) timer session → session settles via LifeTown.Economy.Core → EXP/coins → building
growth/level shown in the village. Wire the three finished foundations into the village scene:
- LifeTown.Economy.Core (T002, 99pt): EconomyConfig, Settlement, session math — pure C#, already tested
- LifeTown.Platform (T003, 99pt): Android-safe clock + save-file IO — sessions must survive app restart
- Art design system (T004, 92pt): docs/design/00-art-design-system.md — colors/type/spacing;
  bake the 7 category hex into a CategoryDef ScriptableObject (Core does NOT have colors — known trap)

## Acceptance criteria
- [ ] Tap a building → timer UI starts; finish (or debug-skip) → settlement runs → EXP/coin gain visible
- [ ] Building growth/level visibly changes in the village after enough sessions
- [ ] State persists across app restart (Platform save IO actually used)
- [ ] Timer/economy numbers come from EconomyConfig, not hardcoded (D5 curve [0,60,240,720,2000], D9 leisure ×1.0)
- [ ] Gate green; existing 81 tests intact + new tests for the wiring layer
- [ ] QA evidence: a real run start-to-settlement with screenshots
